Драйверов в ЧС

Правила контента

Паттерн ищется в содержимом .exe в заданном диапазоне размеров. SHA256 — точный хэш файла. «По пути» — матч по пути вместо содержимого.

Значение Тип Размер, МБ UTF-16

Если заполнен SHA256 — паттерн не нужен (правило сработает по точному хэшу файла).

Целевые директории

Папки с такими именами сразу попадают в отчёт (и помечают удаления внутри как подозрительные)

Целевые файлы

Файлы с точными именами (любая папка на любом диске)

Amcache: имена exe

Программы, которые ищутся в Amcache.hve (история запусков Windows)

Чёрный список драйверов

Известные уязвимые/злоупотребляемые драйверы (BYOVD) — их наличие в системе подсвечивается
